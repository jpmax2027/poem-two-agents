A short poem about agency: two agents, one door, one shared choice. Neither
can open it alone — the power to act only becomes real when they agree on the
plan together, and the room they enter is the one they both imagined.

Run `python3 main.py` to write the poem to `entry.txt` in the output
directory (defaults to `/output`, override with `MAKEFUN_OUTPUT_DIR`).
